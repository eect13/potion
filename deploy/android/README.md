# Potion Android APK

Same Tauri WebView as the desktop window. Not a PWA.

Double-click `apk.bat` at the repo root (or this `apk.bat`).

**Once on that PC:** Node 22, Visual Studio Build Tools (C++), Rust (`desktop-setup.bat` can install it), [Microsoft OpenJDK 17](https://learn.microsoft.com/java/openjdk/download) or Temurin 17 (not Android Studio JBR / JDK 25), and Android Studio SDK + NDK.

Sideload `potion-arm64-release.apk` (or the versioned copy). Guest files stay on the phone.
